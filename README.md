# 行测小助手

行政职业能力测验刷题微信小程序。覆盖行测五大模块：常识判断、言语理解、数量关系、判断推理、资料分析。

## 技术栈

- **前端**：微信小程序原生开发（WXML / WXSS / JavaScript），无第三方 UI 框架，零 npm 运行时依赖
- **后端**：微信云开发（CloudBase）—— 云函数 + 云数据库 + 云存储 + 定时触发器
- **最低基础库**：2.25.0

## 功能

| 模块 | 说明 |
|---|---|
| 专项练习 | 按五大模块抽题，难度按历史正确率动态配比，答完即时出解析 |
| 错题本 | 自动收集错题，连续答对 2 次自动判定掌握 |
| 每日打卡 | 每日 10 题，打卡日历、连续天数、订阅消息提醒 |
| 排行榜 | 周榜 / 总榜，云端缓存定时刷新 |
| 学习战报 | Canvas 2D 生成海报，带邀请参数的小程序码做增长归因 |

## 快速开始

```bash
# 1. 安装微信开发者工具，导入本项目目录

# 2. 开通云开发，拿到环境 ID 后配置本地环境
cp miniprogram/config.example.js miniprogram/config.js
# 编辑 config.js，填入真实云环境 ID

# 3. project.config.json 里的 appid 换成你们的小程序 AppID

# 4. 建数据库集合与索引
#    见 database/schema.md 和 database/indexes.md
#    注意：所有集合安全规则设为「仅管理端可读写」

# 5. 部署云函数（每个云函数目录右键 → 上传并部署 → 云端安装依赖）

# 6. 导入题库
node scripts/import-questions.js <你的题库.csv>
# 产物在 database/import/，用云开发控制台导入 questions 集合
```

详细架构说明见 [`docs/架构设计.md`](docs/架构设计.md)，
版本管理与发布流程见 [`docs/版本管理规范.md`](docs/版本管理规范.md)。

## 两点需要留意

**题库版权**：历年真题原文与官方解析不能直接搬运。本项目 `questions.source` 字段要求如实标注来源，建议全部自研或深度改编。这是教育类小程序被投诉下架的头号原因。

**小程序没有热更新**：代码包改一个字就要重新提审。凡是能用云函数或数据库配置解决的，都不要写死在小程序代码里。

## 分支

- `main` —— 线上正式版，受保护
- `develop` —— 日常开发集成分支，对应体验版
