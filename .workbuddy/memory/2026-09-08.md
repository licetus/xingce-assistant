## 点收藏解析折叠修复（15:10，✅ commit 1b12d6d）

- 现象：点收藏时已展开的解析折叠回去
- 根因：setData(list[i].faved) 把整个 item 重传给组件 → q property observer
  对同题重复触发 → showAnalysis 重置 false、chosen 清空
- **连带发现的隐藏 bug**：提交答案 setData(list[i].result) 同样触发 q observer，
  chosen 被清 → viewOptions.isWrong 依赖 isChosen 恒 false（错选标红失效过！
  用户当时只验证了 isRight 所以没发现）
- 修复：observer q 记录 _lastQid，同题（qid 未变）直接 return，换题才重置。
  对任意 list[i] 子字段更新（faved/result/未来的 done 标记）都免疫
- 通用教训：**「页面路径 setData(item 子字段) → 组件 property 重传 → observer
  重复触发」是小程序组件经典坑，带重置逻辑的 observer 必须做同值防御（qid/时间戳）**
