### 经验沉淀

- **GitHub SSH 鉴权排查套路**：`ssh -vT git@github.com` 看清是公钥没添（"Permission denied"）
  还是其他原因，比 ssh-add / config debug 快十倍
- **远端 default branch 可能是空仓库**：第一次 push 时 `git ls-remote` 只看到一个 ref
  是常态，新建 main 用 `git push -u origin main` 即可，无需 force
- **批量 commit 拆分原则**：CI / 环境 / 文档 / memory 分开提交，回滚粒度精确
  （回滚 CI 不必连带回滚 docs）
