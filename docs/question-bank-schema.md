# 题库 Schema 文档

`scripts/import-questions.js` 消费的题库数据格式说明。
按本格式录入即可直接导入微信云开发 questions 集合。

---

## 字段一览

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `qid` | int | 自动 | 题号，自动生成，无需录入 |
| `module` | string | ✅ | 模块名，5 选 1，**写入时校验** |
| `subtype` | string | | 二级考点（如「主旨概括」「意图判断」），自由文本 |
| `type` | string | 自动 | `single` / `multi`，脚本自动判 |
| `stem` | string | ✅ | 题干，不能为空 |
| `options` | array | ✅ | 选项列表，**至少 2 项** |
| `answer` | array | ✅ | 正确答案，如 `["A"]` 或 `["A","C"]` |
| `analysis` | string | ✅ | 解析，**至少 5 字符** |
| `difficulty` | int | | 1~5 难度，默认 3 |
| `tags` | array | | 标签，**最多 5 个** |
| `materialId` | string/null | | 资料分析题组的关联 ID，单题填 null |
| `images` | array | | 题干图（资料分析常见），空数组 |
| `source` | string | | 出处，默认 `"self"` |
| `status` | int | | `1` 启用 / `0` 禁用，默认 1 |
| `stat` | object | | 统计初始 `{done:0, correct:0}` |
| `createdAt` | object | | 创建时间，脚本自动填 |

---

## 模块名（module）

**写入时容错**——以下任何写法脚本都会归一化为标准模块名：

| 标准名 | 容错的写法 |
|---|---|
| `常识判断` | `常识`、`常识判断`、`公共基础知识` |
| `言语理解` | `言语`、`言语理解与表达`、`言语理解` |
| `数量关系` | `数量`、`数量关系`、`数学运算` |
| `判断推理` | `判断`、`判断推理`、`推理` |
| `资料分析` | `资料`、`资料分析` |

**写错也无所谓**——脚本 `normalizeModule()` 会做最长公共子串匹配。

---

## 选项格式

- `options` 是数组，每项 `{key: "A", text: "选项文本"}`
- **至少 2 项**（通常 4 项 A/B/C/D）
- 如果某选项为空，**脚本会自动剔除**（所以 3 项选项也 OK）
- 多选题答案里出现的字母，必须在 `options` 里能找到对应项

---

## 答案格式

- 必须是**数组**形式（支持多选题）
- 单选：`["A"]`
- 多选：`["A","C"]`
- 自动转大写、自动去非 ABCD 字符
- **必须能对应到选项 key**——否则报错「答案不在选项内」

---

## 难度（difficulty）

1~5 的整数，默认 3。脚本会校验：

- 1 = 简单（常识 / 基础运算）
- 2 = 较易
- 3 = 中等（默认）
- 4 = 较难
- 5 = 困难（数量关系 / 资料分析计算题）

---

## 标签（tags）

- 用英文逗号 `,` 或中文 `，` 或顿号 `、` 或竖线 `|` 分隔
- **最多 5 个**
- 自动 trim 空值
- 示例：`"速算,基期量,估算"`

## ✅ 完整示例

### CSV 格式（最常用）

```csv
module,subtype,stem,A,B,C,D,answer,analysis,difficulty,tags
言语理解,主旨概括,以下哪个选项最适合做文章的标题？,春天的故事,夏天的回忆,秋天的思考,冬天的感悟,A,文章通过四季更迭表达对时间的感悟，选 D 不准确，选 A 最能体现全文主旨。",2,标题题,主旨
数量关系,工程问题,一项工程甲单独做 10 天完成，乙单独做 15 天完成，两人合作多少天完成？,5,6,8,10,B,合作效率=1/10+1/15=1/6,所以需要 6 天。,3,工程问题
常识判断,法律基础,中华人民共和国宪法是我国的根本法，由（）制定。,全国人民代表大会,全国人大常委会,国务院,最高人民法院,A,宪法第 58 条规定由全国人民代表大会制定和修改。,2,宪法
判断推理,图形推理,给出 4 个图形，问第 5 个应填入哪个选项使之符合规律。,选项A描述,选项B描述,选项C描述,选项D描述,C,观察图形元素递增规律，应选 C。,3,图形推理
资料分析,增长率,某省 2024 年 GDP 同比增长 6.5%,2023 年增长 7.2%,据此判断 2024 年...,选项A,选项B,选项C,选项D,A,6.5%<7.2%,增速回落,故选 A。,3,增长率,GDP
```

> ⚠️ CSV 含逗号或引号时，**必须**用双引号包整字段，内部引号用 `""` 转义。

### JSON 格式

```json
[
  {
    "module": "言语理解",
    "subtype": "主旨概括",
    "stem": "以下哪个选项最适合做文章的标题？",
    "options": [
      {"key": "A", "text": "春天的故事"},
      {"key": "B", "text": "夏天的回忆"},
      {"key": "C", "text": "秋天的思考"},
      {"key": "D", "text": "冬天的感悟"}
    ],
    "answer": ["A"],
    "analysis": "文章通过四季更迭表达对时间的感悟，D 不准确，A 最能体现全文主旨。",
    "difficulty": 2,
    "tags": ["标题题", "主旨"]
  }
]
```

> qid / type / status / stat / createdAt 都由脚本自动生成，**无需在 JSON 里写**。

---

## ⚠️ 校验规则（脚本会自动跑）

| 规则 | 错误提示 |
|---|---|
| module 不在 5 个标准名内 | `模块无法识别` |
| stem 为空 | `题干为空` |
| options 少于 2 项 | `选项少于 2 个` |
| answer 为空 | `答案为空` |
| answer 里有选项里没有的字母 | `答案不在选项内` |
| analysis 为空或 < 5 字符 | `解析缺失或过短` |
| 同 stem 重复 | `题干重复`（按 md5 去重） |

校验失败会写入 `database/import/invalid.json`，方便回查补录。

---

## 🚀 一键导入流程

```bash
# 1. 把题库按上面 CSV 格式录入到 questions.csv
# 2. 跑脚本（自动校验 + 切片 + 输出 JSON Lines）
node scripts/import-questions.js ./questions.csv

# 3. 输出会切片成 N 个文件（每 1000 题一个）：
#    database/import/questions_001.json
#    database/import/questions_002.json
#    ...

# 4. 微信开发者工具 → 云开发控制台 → 数据库 → questions 集合 → 导入
#    （必须选 JSON Lines 格式，每个文件不超过 1 万条）
```

## 进阶：资料分析题组（materialId）

资料分析是「一组资料 + 5 道题」的形式，需要关联：

1. 先创建 `materials` 集合的文档，每条资料一个 `_id`
2. 题组里每道题填 `materialId: "<那个 _id>"`
3. 导入顺序：先 materials → 再 questions

> V1.0 题组关联可暂缓，单题导入也能展示（仅失去「同一资料下题与题的视觉关联」）。

## 字段名容错（CSV 表头可混用）

脚本对 CSV 表头做了**中英文容错**，下面这些列名等价：

| 标准字段 | 等价写法 |
|---|---|
| `module` | `模块` / `题型` / `专项` / `category` |
| `subtype` | `二级考点` / `考点` / `知识点` / `tag` |
| `stem` | `题干` / `题目` / `question` / `title` |
| `A/B/C/D` | `选项A` / `optionA` / `option_a` |
| `answer` | `答案` / `正确答案` / `correct` |
| `analysis` | `解析` / `explanation` / `explain` |
| `difficulty` | `难度` / `level` |
| `tags` | `标签` / `labels` |

直接 Excel 录入后另存 CSV 即可，无需重命名表头。
