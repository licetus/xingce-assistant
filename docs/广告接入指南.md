|---|---|---|---|---|
| **激励视频** | 全屏视频，看完发奖励 | 用户主动观看 | 最高（约 50~120 元） | ✅ 已封装 `showVideoAd()`，V1.1「看广告解锁 AI 出题」 |

**结论**：刷题工具的最优组合就是本项目已就绪的两类——**激励视频（主力变现）+ 首页单个 Banner（保底）**，其余类型要么打扰体验、要么没有匹配场景。

## 二、前提条件：开通流量主

1. **门槛**：小程序累计独立访客（UV）不低于 **500**（2026 年门槛已从 1000 下调）。V1 上线后积累达标会比预期快。
2. **入口**：微信公众平台（mp.weixin.qq.com）→ 左侧「流量主」→ 开通。
   企业主体直接开通；开通后可在「广告位管理」创建广告位。
3. **创建广告位**：
   - **Banner 广告** → 命名「首页底部」→ 得到形如 `adunit-xxxxxxxxxx` 的广告位 ID
   - **激励视频广告** → 命名「AI 出题解锁」（V1.1 启用）→ 同样得到 `adunit-` 开头的 ID

> ⚠️ 广告位 ID 固定 `adunit-` 前缀。代码里做了格式校验，填错的内容会被视为「未启用」静默忽略，不会报错。

## 三、启用广告（填配置即可）

云开发控制台 → 云数据库 → `config` 集合 → 找到对应文档把 `value` 改为广告位 ID：

| key | 广告形式 | 展示位置 | 建议启用时机 |
|---|---|---|---|
| `ad_banner_home` | Banner | 首页底部快捷入口下方 | 流量主开通后即可开 |
| `ad_interstitial` | 插屏 | 开启小程序时自动触发；**3 小时全局冷却 + 上午（04:00–12:00）/ 下午（12:00–18:00）/ 晚上（18:00–次日 04:00）各最多 1 次，全天 ≤3 次**，频控记在用户本地，加载失败不消耗次数 | 流量主开通后即可开；注意提审合规——插屏禁止高频弹出 |
| `ad_video` | 激励视频 | 由业务逻辑调起（暂无调用点） | V1.1 AI 出题功能上线时 |

**生效方式**：无需发版。用户下次冷启动时 `login` 云函数把 config 全量下发，广告即刻出现；
**关闭方式**：把对应 `value` 清空即可，同样即时生效。

**临时关停**（如过审后需短暂关闭、或收到用户投诉）：控制台把 `audit_mode` 置 `true`，
全站广告（连同排行榜、邀请入口）一起隐藏；改回 `false` 恢复。

## 四、代码侧说明（开发者参考）

- **配置读取**：`utils/ad.js` → `bannerId(key)`。校验 `adunit-` 前缀 + `app.canShow('ad')` 审核守卫，不合法一律返回空串。
- **Banner**：首页 `index.wxml` 的 `<ad>` 组件，`wx:if` 控制渲染；`binderror`（无填充/未开通/网络异常）自动隐藏容器。
- **激励视频**：`showVideoAd()` 返回 Promise，`true` = 完整观看（应发奖励）、`false` = 中途退出/失败/未启用。内部处理了单例复用（重复 `createRewardedVideoAd` 有配额坑）、配置热更换重建实例、首次 `show` 失败二次拉起。
- **测试**：`test/unit/ad.test.js` 8 个用例，覆盖格式校验、审核模式、单例、完整/中断观看、失败降级。
- **调用示例**（V1.1）：

```js
const ad = require('../../utils/ad');

const completed = await ad.showVideoAd();
if (completed) {
  // 发放奖励：解锁 AI 出题次数等
}
```

## 五、合规红线（审核重点，务必遵守）

1. **不得诱导点击**：不能用「点击领取」「点击有惊喜」等文案引导用户点广告。
2. **不得遮挡广告**：任何浮层、弹窗、悬浮按钮不得覆盖广告区域。
3. **激励视频奖励必须真实**：看完（`isEnded`）才发奖励，提前退出不发——代码已按此实现，业务侧不要绕过。
4. **文案规范**：解锁类文案用「观看视频解锁」，不用误导表述。
5. **提审期间**：`audit_mode=true` 已自动关停广告，审核员看到的是无广告的干净版本。

违反以上任一条，轻则驳回重审，重则封禁流量主资格。

## 六、收益预期与管理建议

- **Banner** eCPM 较低（工具类目通常几元/千次曝光），胜在零打扰、全自动。
- **激励视频** eCPM 显著更高，且用户主动观看、体验无损伤，是工具类小程序的主力变现形式——建议 V1.1 优先做「看广告解锁 AI 出题次数」这类场景。
- **克制原则**：刷题工具的核心价值是「无干扰」。建议 V1 只保留首页一个 Banner，不进刷题页（做题中途出广告会直接伤害完课率和留存）。
- 后台「流量主 → 数据分析」可看各广告位收益，据此决定是否加密度。

## 七、常见问题排查

| 现象 | 排查顺序 |
|---|---|
| 广告完全不显示 | ① config 的 ID 是否填了且 `adunit-` 开头 → ② `audit_mode` 是否为 true → ③ 开发者工具里 `binderror` 是否触发（未开通流量主时必触发） |
| 广告时有时无 | 正常现象，微信广告有填充率概念，无填充时平台不出广告，代码自动隐藏 |
| 激励视频看完没发奖励 | 检查业务代码是否用 `showVideoAd()` 返回值判断，而非 `onClose` 直接发 |
| 真机有广告、工具里没有 | 正常，部分广告类型不在开发者工具渲染，以真机为准 |
