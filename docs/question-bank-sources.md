# 题库来源指南

> ⚠️ **2026-09-07 调研更新**：国家公务员局（scs.gov.cn）8 月底下线，专题网站（bm.scs.gov.cn）只服务当年度考试，**官方不长期在线托管历年真题**。原文档"去 scs.gov.cn 下载"的推荐路径作废。

行测小程序的题库是**合规红线**（ICP 备案 + 微信类目审核 + 国家版权都会查）。
本页只列**合法、可商用**的获取路径，附实操建议。

## ✅ 推荐路径

### 1. 用户自购真题集 + 自主编写解析（**最推荐**）

**操作**：
1. 淘宝 / 京东 / 孔夫子旧书网 搜 `2024 国考行测真题` / `2025 国考行测真题` / `2026 国考行测真题`
2. 选**正规出版社**（中国人事出版社、华图、粉笔、中公等）的纸质书（15~50 元/本）
3. 拍照或扫描上传给我
4. 我解析 PDF / 图片 → 按 schema 生成 CSV 模板
5. **你自己**填解析（版权完全自有，审核无忧）

**优势**：
- ✅ 真题题干权威（来自官方考试用卷）
- ✅ 解析完全自研 → **版权完全自有** → 微信审核 + 国家版权双保险
- ✅ 成本极低（30 元解决 1000+ 题）

**缺点**：
- ⚠️ 需要你自己花时间写解析（5 模块约 200~500 题，按每题 100 字解析 ≈ 2~5 万字）

### 2. 用往年国家公务员局发布的真题（题干来源）

> **重要**：scs.gov.cn 主站 2026 年 8 月底下线，`bm.scs.gov.cn/kl{year}` 专题网站只在考试年度存活（约 1~2 年）。

**操作**：
1. 找近期还在存活或被镜像的官方公告页（如：`http://bm.scs.gov.cn/kl2026/`）
2. **仅复制题干原文**——这是政府公开信息，可商用
3. **不要复制任何第三方培训机构或出版社的解析 / 排版 / 配图 / 考点分类**

**优势**：题干权威 + 零成本

**缺点**：
- ❌ 找不到完整历年归档
- ❌ 仍需要你自写全部解析
- ❌ 即使拿到题干，版权风险只有"自研解析"才能规避

### 3. AI 生成新题（原创辅助）

用大模型（豆包 / DeepSeek / GPT / Claude）按 5 模块出题：

**适用场景**：
- 拓展题量时作为辅助

**风险**：
- ⚠️ 行测高频考点易与公开题撞题
- ⚠️ 答案正确性需人工校对

## ⚠️ 灰度路径（要谨慎）

### 商业培训机构资源（华图 / 粉笔 / 中公）

| 类型 | 风险 | 说明 |
|---|---|---|
| 公开网站免费真题 PDF | 中 | 解析 + 排版 = 汇编作品，**不可直接录入** |
| 印刷出版物扫描 | 中 | 个人学习可用，**商用需授权** |
| 官方 API / 数据授权 | 低 | 几万到十几万/年，需签约 |

⚠️ **V1.0 不必考虑商业授权**——先用路径 1 跑通上线，等 DAU 起来再评估。

### 开源题库（GitHub）

- 大多许可证只允许**个人学习使用**，**不可商用**
- 即使许可证允许商用，也要追溯上游版权
- **不可控风险**

---

## ❌ 不可行路径（合规 / 实操风险）

### 1. 爬第三方题库（粉笔 App / 一起考 / 华图在线 / 步知等）
- **解析 + 排版 + 配图** = 受版权保护的汇编作品 → **直接侵权**
- 即使只爬题干结构，也可能触发反爬机制 + 法律纠纷
- 微信审核 + 国家版权局 12390 举报通道都会查

### 2. 寄希望于官方网站集中托管历年真题
- ❌ **2026-09-07 实测**：`bm.scs.gov.cn` 历年专题（kl2022~kl2025）全部 404
- ❌ 专题网站资源 API（`/api/res/{hb01Id}/1110`）只列当年**报名表 / 面试名单 / 招考简章**，**无真题**
- ❌ 政府不会长期托管历年真题（避免泄题争议 + 服务器成本）

## ⚠️ 常见误区

- **「真题是公开的，应该都能随便用」** ❌ ——只限题干；任何来自第三方题库的「产品化内容」（解析/排版/考点分类）都受版权保护。
- **「官方网站能下载历年真题」** ❌ ——2026-09-07 实测**不可行**（专题网站考后即归档，无集中 API）。
- **「网上随便搜的解析应该能抄」** ❌ ——除非解析是你自己写的，否则即便来源是公开 PDF，第三方对解析的重新排版、整理也构成汇编作品。
- **「小程序用户量小没人查」** ❌ ——微信审核 + ICP 备案复审 + 国家版权局 12390 举报通道都会触发。

**最稳的做法**：自购纸质真题集（题干）+ 自主编写全部解析。**所有衍生内容全部自研**，这是唯一零风险的路径。
