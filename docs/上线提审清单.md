# 行测小助手 · 上线提审材料清单

> 用于 V1.0 提交微信审核前逐条核对。  
> 标记 ✅ 表示当前已具备，⬜ 表示需外部准备（微信后台 / 主体资质 / ICP 等）。

---

## 一、主体与资质（关键路径，必须提前启动）

| 序号 | 材料 | 说明 | 状态 |
|---|---|---|---|
| 1 | **企业 / 个体工商户营业执照** | 小程序主体必须是企业或个体工商户；个人主体无法开通微信支付，也较难通过工具 / 教育类目。 | ⬜ 需用户准备 |
| 2 | **对公账户** | 微信认证、微信支付开户时需要验证。个体工商户可用法人银行卡替代。 | ⬜ 需用户准备 |
| 3 | **法人身份证正反面** | 小程序认证、备案、支付开户均会用到。 | ⬜ 需用户准备 |
| 4 | **ICP 备案** | 2024 年起所有非境外小程序上架必须完成 ICP 备案。企业主体通常 **3~20 个工作日**，是第一关键路径。 | ⬜ 需用户启动 |
| 5 | **域名（可选）** | 本项目使用微信云开发，不强制自有域名；若未来做 H5 分享页或官网，再额外备案。 | — |

### ICP 备案建议

- 备案入口：微信公众平台 → 设置 → 基本设置 → 去备案。
- 备案期间小程序**仍可开发、仍可提交代码审核**，只是正式上线需要备案完成。
- 所需材料：营业执照、法人身份证、主体负责人联系方式、小程序负责人（可与法人不同）身份证及联系方式、核验单/承诺书（按省份要求）。
- 建议：上架计划倒推，**至少提前 4 周启动备案**。

## 五、隐私保护指引（可直接复制到微信后台）

进入微信公众平台 → 设置 → 基本设置 → 用户隐私保护指引，按以下方式配置：

### 开发者处理的信息

| 信息类型 | 用途 |
|---|---|
| 用户微信头像、昵称 | 用于排行榜、打卡海报、个人中心展示 |
| 微信 openid | 用于用户登录、数据归属、打卡与排行榜统计 |
| 用户答题记录、错题、收藏 | 用于提供刷题、错题本、收藏夹等学习功能 |
| 相册权限（保存海报） | 用于将学习战报海报保存到本地相册 |

### 信息保护说明

- 所有用户数据存储在微信云开发数据库，不对外出售或共享。
- 用户可在「我的」页面查看并修改头像、昵称。
- 用户删除小程序账号后，相关学习数据将在 30 天内删除。

## 六、建议时间线（假设目标 4 周后提审）

| 周次 | 事项 |
|---|---|
| 第 1 周 | 完成 ICP 备案申请；准备营业执照、法人身份证、对公账户；确定小程序名称和类目。 |

| 第 4 周 | 上传代码、提交审核；备案同步跟进；审核通过后发布。 |

## 八、风险提示

1. **类目风险**：如果选择「教育 > 在线教育」，微信可能要求提供《办学许可证》《ICP 经营许可证》或教师资质证明。建议 V1.0 先用「工具 > 效率」降低门槛。
2. **内容风险**：题库必须为用户自研或深度改编，避免直接搬运真题原文和官方解析，否则审核可能被拒。
3. **诱导分享风险**：分享海报、排行榜裂变需避免「强制分享」「分享后才能继续答题」等诱导行为。
4. **备案前置**：2024 年起未备案小程序无法正式发布，务必提前启动，不要等代码审核通过再补。
